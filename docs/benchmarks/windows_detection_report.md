# Windows Detection Evaluation

Generated by `tools/benchmark_windows.py`. 7 rules from `siem/elastic/windows_rules.json` (6 EQL, 1 ES|QL) run in Elasticsearch. The data is five OTRF [Security-Datasets](https://github.com/OTRF/Security-Datasets) captures (MIT licence) and one [EVTX-ATTACK-SAMPLES](https://github.com/sbousseaden/EVTX-ATTACK-SAMPLES) sample (GPL-3.0; kept local and not redistributed, SHA-256 in the JSON report). Together they hold 13,925 events. Every hit is dispositioned by an analyst in [windows_triage.csv](windows_triage.csv). An ES|QL hit is one aggregated row (source, capture, five-minute window), not one event.

## Expected False Positives in Production

- **WIN-001**: Management agents and installers that pass scripts with -EncodedCommand (for example SCCM or Intune scripts). Allow-list them by signed parent process and host group, not by command line.
- **WIN-002**: Security products (Defender MsMpEng.exe, EDR sensors) and Windows Error Reporting legitimately read LSASS memory. Exclude them by verified executable path and signature.
- **WIN-003**: Rare. Troubleshooting sessions may dump processes with comsvcs.dll, but dumping lsass.exe this way should always be investigated.
- **WIN-004**: Software deployment tools and legitimate PsExec use by administrators install short-lived services that run cmd. Correlate with change records.
- **WIN-005**: Administrative and vendor maintenance tasks often run PowerShell. Baseline existing task names per host group and alert on new ones.
- **WIN-006**: Legacy logon or inventory scripts in VBScript that call PowerShell. Allow-list them by script path.
- **WIN-007**: A misconfigured service or a stale mapped drive retrying old credentials across several accounts, and NAT or proxy addresses aggregating many users. Check whether the accounts exist and whether any attempt later succeeded.

## Limits

- Ground truth is per capture. OTRF gives one technique per capture, and each capture also contains normal background activity. Precision here is analyst-reviewed hits in these captures, not a false-positive rate on a production estate.
- The captures come from one lab configuration (Sysmon and audit policy) recorded in 2020. Rules depending on 4688 command lines or Sysmon 10 need the same logging.
- `empire_psexec_dcerpc_tcp_svcctl` is mapped by OTRF to T1021 Remote Services. WIN-004 detects the service-execution part (T1543.003, T1569.002), not the remote logon itself.
- The spraying sample holds 12 events from one source within one second; it proves the rule logic, not its threshold on real domain-controller volume. NTLM brute force (4625) and Kerberoasting (4769) have no public sample here and remain untested.
